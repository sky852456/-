# 🧭 旅行规划 · Travel Planner

一个**装在手机上的私人旅行管家**——行程、地图、天气、票务、记账、酒店、手账、小视频，全在一处。

它原本是一个单文件 HTML，现在升级成了 **PWA（渐进式 Web 应用）**：可以添加到手机主屏、点开就是全屏、**断网也能用**，还带一个 AI 助手（本地模型免费跑，或接云端接口，可联网搜索）。

> 💡 **一句话理解**：它是一个「不用上架应用商店的 App」。放到任意免费托管上，手机打开、添加到主屏，从此就像原生应用一样用。
>
> 📌 当前版本 **v1.8.4**（Service Worker 版本号与之一致）。本期聚焦**离线优先**——针对无信号路段（如青甘大环线沿途）强化离线可用性；出发前追加：**票务截图 OCR 自动填**、**门票预约票自动进行程 + 当日时间线**、**主页 ✨ AI 目的地攻略（支持海外 + 开放推荐）**。

### 几个贴心设计

- **建议 → 采纳 → 才写入**：知识库和 AI 只给建议，你点了「采纳」才会写进数据，不会乱改你的行程
- **一切可离线**：应用本体、地图库、知识库都会缓存到本地，飞机上也能改行程
- **隐私优先**：OCR 在本地跑，本地 AI 也在设备上推理，不需要上传任何东西
- **容错做得厚**：图标丢了会自动兜底、经纬度写反了会自动纠正、分享文本被截断会说人话告诉你

## 🌤️ 天气怎么用

- **当日天气卡**：打开某一天就自动加载，显示天气图标、气温区间、降水概率、海拔，以及一句出行提示（该不该带伞、要不要防晒）。
- **总览全程天气**：总览页会一次拉齐全程每天的天气，横向一排看完「这几天穿什么」。
- **不需要定位授权**：它用的是行程里**已有的景点坐标**去查，没有坐标时会用城市名做地理编码兜底。
- **免 API key**：走 Open-Meteo 公共接口，浏览器直连，2 小时缓存，不刷请求。
- **📴 离线快照（v1.8.0 新增）**：每次联网成功拉到天气后，会按坐标把 JSON 存进浏览器本地（最多 30 个坐标，自动 LRU 淘汰旧的）。一旦断网、接口超时或请求失败，会自动渲染这张快照，并标注「📴 离线快照 · 更新于 X 小时前（联网后自动刷新）」。**超过 48 小时**的旧快照不会留白，而是给一句友好提示让你知道数据可能偏旧；联网后下一次打开会自动刷新为实时数据。天气数据本身仍走网络（Service Worker 不缓存实时接口），离线可见靠的是这张应用层快照。
- **超 16 天的行程**：Open-Meteo 预报窗口有限，超出范围会给友好提示而不是报错。

> 🩺 已知会自愈的问题：早期版本里「经纬度写反」（纬度填成了 103）会导致请求 400，现在打开应用会自动纠正并落盘；日期计算也改为本地日期推算，不再因时区倒退一天。

## 🚄 交通票务：截图 OCR 自动填（v1.8.1 新增，v1.8.2 支持门票）

出发前录入一堆车票机票很烦？现在可以**截图订单/登机牌，本地一键识别并预填**。

- **完全本地**：用 Tesseract.js 在浏览器内识别，**图片不上传**任何服务器（首次需从 CDN 加载语言包，约 10–30 秒）。
- **支持来源**：12306 / 携程 / 航旅纵横 / 航司 App 的订单页或登机牌截图。
- **自动提取**：班次/航班号、类型（高铁/航班/火车/大巴/轮渡）、日期、出发/到达时间、出发地/到达地、票价、座位/舱位——识别到的项会**直接预填到录入表单**。
- **认准「核对」**：OCR 是本地识别，地名/站名偶有偏差，**填完请核对一遍再点「添加」**；识别不到的留空，你补即可。

**📍 操作路径**：行程编辑页 → 🚄 交通票务面板 → `📷 票务截图识别` → 选截图 → 等识别 → 自动弹出已预填的表单 → 核对 → 添加。

### 🎫 门票 / 预约票：自动写入当日行程 + 当日时间线（v1.8.2 新增）

门票、预约票（如博物馆/景区预约单）截图识别后，不只是预填票务——还能**按场次时间自动写进当天行程**。

- **自动提取**：使用日期、**场次时间**（如 15:00–16:00）、场馆名（博物馆/美术馆/景区等）、入园地址、票种、「凭身份证入园」提示。
- **一键进行程**：表单里默认勾选「**按时间同步写入当日行程**」，点添加后该场馆会**按场次时间顺序插入当天点位**，时长按场次自动推算。
- **当日时间线**：打开任意一天的明细，顶部有一张「**🕐 当日时间线 · 几点做什么**」卡——把当天的交通班次、门票场次、填了计划时间的点位**按时刻排序**，两段安排之间空档 ≥ 40 分钟会提示「⏳ 空闲 · 可自由安排」，没定时间的点位列在末尾提醒你补。
- 景点编辑表单新增「**计划开始时间**」（选填），填了就会进时间线。

**📍 操作路径**：行程编辑页 → 🚄 交通票务 → `📷 票务截图识别`（选预约票截图）→ 核对预填 → 添加 → 到该日明细看「🕐 当日时间线」。

> 💡 若提示「OCR 引擎未加载」，说明当前网络打不开 cdn.jsdelivr.net，改用面板里的 `➕ 录入票务` 手动填即可。本功能与离线能力不冲突：识别是出发前在线时做的事，填好的数据照常离线可用。

## 📴 离线优先（本期重点）

> 🎯 **为什么做这期**：9/29 就要出发走**青甘大环线**，沿途大段路段没有手机信号。这期不堆新功能，专门把**离线保命**的几件事做扎实——地图有底图、天气看得到、资料查得着、数据不丢。下面 4 项都是**出发前必做**。

### P0-1 · 地图瓦片离线预缓存 📦

出发前把沿途高德底图提前下到手机，无信号路段拖动地图也**有底图**，不是空白。

- **缓存范围**：自动遍历当前行程里的**所有景点 + 酒店**（高德 GCJ-02 坐标），对每个点枚举 **z10 / z12 / z14** 三级缩放的瓦片，半径分别 5km / 2km / 1km（bbox 取整）。
- **去重合并**：多个景点附近的瓦片自动去重，不会重复下载。
- **写入位置**：存进浏览器 **Cache Storage** 的独立库 `travel-tiles-v1`（与应用外壳缓存分离，版本升级不会被清掉）。
- **进度可视**：点开后弹窗里有**进度条 + 实时计数**；单张瓦片失败**自动重试 1 次**；完成后提示缓存了多少张。
- **上限保护**：缓存瓦片数超过 **5000** 时会自动按 LRU（最久未用）淘汰，避免撑爆空间。
- **离线命中策略**：Service Worker 对 `webrd/webst*.is.autonavi.com` 瓦片走「**先查缓存，命中即返回；未命中再联网并回填；离线则报错**」，上限 5000 张 LRU。预缓存用**固定子域 `1`**，保证和地图实际请求 URL 一致，离线必中。

**📍 操作路径（两个入口，任选）**

| 入口 | 在哪 | 按钮 |
|---|---|---|
| 总览页 | 行程**总览**页底部操作区（「导出行程长图」旁边） | `📦 预缓存地图`（ovPrecache） |
| 编辑页 | 切到**编辑视图** → 路线地图面板右上角 | `📦 预缓存地图`（btnPrecache） |

> 点开弹窗 →（可选）勾选包含酒店点 → 点「开始预缓存」→ 等进度条跑完 → 看到「已缓存 N 张」即代表离线底图就绪。建议在**有 WiFi** 时做，约几百到上千张瓦片。

### P0-2 · 行前离线自检清单 🧳

一个逐项打勾的清单，出发前 5 分钟跑一遍，确认该准备的全备好了。

**📍 操作路径**：左侧「**行程目录**」侧边栏底部 → `🧳 行前自检`（btnSelfCheck）

清单会逐项检查并标绿/标红：

1. ✅ **Service Worker 已激活**（离线能力的总开关）
2. ✅ **离线瓦片数量**（就是上面 P0-1 缓存的张数，为 0 会提醒你先去预缓存）
3. ✅ **知识库条目数**（SPOT_KB + CITY_FOOD_KB + GEO_BUILTIN 总数，沿途景点资料查得着）
4. ✅ **本地 AI 模型就绪**（WebLLM 是否已下载，断网也能问 AI）
5. ✅ **上次导出时间**（**从未导出会标红**，提醒你先备份）
6. 💡 **语音备忘离线提示**（固定说明：语音备忘在离线时也能录，回来再整理）

**全部通过**会显示「🟢 可以出发 ✅」；有任何一项没过关，会告诉你缺什么、去哪补。

### P0-3 · 天气离线快照 📴

（功能细节见上方「🌤️ 天气怎么用」章节「📴 离线快照」一段）一句话回顾：**联网拉到的天气会本地存盘，断网自动显示快照**，不会白屏。

- 存 `localStorage` 键 `TP_WEATHER_SNAPSHOT`，最多 30 个坐标，LRU 淘汰。
- 断网/超时/失败 → 渲染快照并标注「更新于 X 小时前」。
- 超过 48 小时的旧快照给友好提示而非空白；联网后自动刷新。
- 天气接口本身仍是 **Network Only**（Service Worker 不缓存实时接口），离线可见靠应用层快照，符合「断网看得到、联网自动新」的设计。

### P0-4 · 备份提醒（防丢数据）💾

改了行程却忘了导出？这个会提醒你。

- **自动脏标记**：每次 `保存` 改了数据就标记为「脏」；每次 `导出备份` 就清脏并记录「上次导出时间」。
- **触发时机**：① 打开应用时；② 每天 **21:00**（页面存活期间）。
- **提醒条件**：数据「脏」且距上次导出 **> 24 小时** → 底部弹出**非阻塞提示条**，带**一键导出**按钮；每天最多弹 1 次。
- **「今天不提醒」**：点一下，当天不再弹，第二天照常检查。
- **老数据无损升级**：从旧版 `TRAVEL_PLANNER_V1` 升级时，会**先自动备份一份**再迁移，不会丢数据。

## 🤖 AI 助手

### ✨ 目的地攻略（主页，v1.8.3 新增）

还在纠结「下次去哪玩、怎么排、要花多少钱」？主页点 **`✨ AI 攻略`**：填目的地（有常用线路快捷标签）、天数、人数、出行方式，AI 生成一份结构化攻略：

- **行程框架**：仿「Day 1-2 贵阳：…」的分段式框架，按地理顺路安排，每段附主要景点标签；
- **预算参考**：交通/住宿/餐饮/门票/总计 + 一句话旺季提醒；
- **风景描述**：一段话讲清这条线最标志性的景观体验；
- **风景配图**：自动从 Wikimedia Commons 免费图库按「城市+标志景观」搜图，加载失败自动退回文字描述（部分网络环境访问不了图库，属正常兜底）；
- **国内外都支持**：快捷标签分国内（贵州/桂林/川西/青甘…）和海外两组（日本关西 7 天、东京+镰仓、泰国、巴厘岛、土耳其、新马），海外标签点一下自动带出天数；海外攻略预算额外含**签证**行、提示含办签周期；
- **开放推荐模式**：**目的地留空** + 补充要求写「五一最推荐去哪」「十一 7 天不贵又好玩」→ AI 直接推荐目的地并给**推荐理由卡**（💡 黄色卡片），天数也由 AI 定；两者都留空会被拦截提示，不会空转；
- **一键导入**：点「导入为新行程」→ 自动建成旅行档案（日期从今天顺排、景点生成空点位），接着用编辑页/OCR 把坐标票务补全即可；
- 生成失败或格式不稳时，会展示 AI 原文并可复制，不白等。

> 💡 效果排序：云端 AI（联网搜索，最新信息）> 本地模型（免费断网可用，攻略偏通用）。云端未配置 Key 时会引导你去 AI 助手配置。

右下角的 **🤖 悬浮按钮**就是入口。有两种模式，随时可切：

### 模式一：本地模型（完全免费）

用 [WebLLM](https://github.com/mlc-ai/web-llm) 把 **Qwen2.5-3B** 直接跑在你的设备上。

| 特性 | 说明 |
|---|---|
| **费用** | **完全免费**，没有 API key、不按次计费 |
| **后端** | **不需要**，纯前端 |
| **隐私** | 数据**不出设备** |

## 📲 跨设备同步（三种方式）

手机上排好行程，想在电脑上看？**推荐顺序**：复制分享文本 > 备份文件 > 扫码。

| 方式 | 怎么用 | 适合 |
|---|---|---|
| 📋 **复制分享文本** | 手机「导出 → 复制分享文本」→ 微信发给自己 → 电脑「导入 → 从分享文本导入」粘贴 | 手机↔电脑，**最稳** |
| 📂 **备份文件** | 「导出 → 下载备份 .json」→ 另一台设备「导入 → 从备份文件导入」 | 长期备份、大行程 |
| 📷 **扫码导入** | 手机生成二维码（按数据量自适应放大）→ 另一台设备扫码 | 面对面快传 |

**排错常识**：

- 分享文本是一串以 `G` 或 `B` 开头的字符（gzip+base64 或纯 base64），**必须完整复制**，中途截断会解码失败。
- 复制超过 2200 字符时会提前提醒你「字符很长，建议改用备份文件」。
- 粘贴失败时弹窗**不会关掉**，会原地告诉你原因（像不像分享码、是不是被截断了），并提供「改用文件导入」按钮。
- 扫不出来多半是二维码太密或扫错了别的码，导出时已自动放大；实在不行就换文件导入。

## ❓ 常见问题

**Q：手机打开还是浏览器界面，有地址栏？**
A：说明没添加到主屏。必须按上面的方式添加，从桌面图标打开才是全屏。

**Q：图标是灰色的 G / 图标不显示？**
A：① 你点的可能是「创建快捷方式」而非「安装应用」；② `icons/` 没传对（但 `icons.js` 会自动兜底）；③ 浏览器缓存了旧 manifest，清站点数据后重开。

**Q：天气加载不出来？**
A：三种常见原因都已自动处理——经纬度写反会自动纠正、日期时区问题已修、超出 16 天预报窗口会提示。若仍为空，多是首次访问 `open-meteo.com` 被网络拦了，换个网络再试。

**Q：「一键定位」和「我的位置」有什么区别？**
A：两个完全不同的功能：
- **📍 一键定位**：把行程里**还没坐标的景点/酒店**批量查经纬度（需配高德 Key）
- **🧭 我的位置**：显示**你本人现在在哪**，蓝点实时刷新（需浏览器定位授权）

**Q：定位点不动 / 授权失败？**
A：需要 **https** + **浏览器授权**（首次弹窗选「允许」，误拒可去地址栏左侧站点设置改回）+ **联网**。室内 GPS 弱时精度降到几百米属正常。

**Q：AI 报 `Failed to fetch`？**
A：本地模型下载失败。确认用的是 Chrome/Edge，且能访问 `modelscope.cn`。重新点功能会**从断点续传**。

**Q：粘贴分享文本提示解码失败？**
A：文本被截断了（常见于手机→电脑的长字符搬运）。改用「备份文件」导入，或重新完整复制一次。

**Q：改了文件但页面没更新？**
A：Service Worker 缓存。清一下站点数据，或留意应用内「✨ 有新版本可用」提示（会自动弹）。

**Q：iPhone 没看到安装提示？**
A：iOS 不支持自动安装提示。打开约 6 秒后会弹出图文教程，照着做即可。

## 🛠 技术栈

| 层面 | 用了什么 |
|---|---|
| **形态** | 单页 HTML + 原生 JS（无框架、无构建步骤） |
| **PWA** | Web App Manifest + Service Worker（三级缓存策略） |
| **地图** | Leaflet + 高德瓦片（GCJ-02，含 WGS-84 纠偏） |
| **天气** | Open-Meteo（forecast + geocoding，免 key，WMO 码映射） |
| **AI** | WebLLM + Qwen2.5-3B（WebGPU 本地推理）/ 云端 OpenAI 兼容接口 |
| **OCR** | Tesseract.js（本地识别，图片不上传） |
| **二维码** | qrcodejs（生成）+ jsQR（扫描），纯前端跨设备同步 |
| **视频** | Canvas captureStream + MediaRecorder（1080×1920） |
| **存储** | localStorage（预留云同步接口） |

### Service Worker 三级缓存策略

| 类型 | 策略 | 说明 |
|---|---|---|
| 应用外壳（HTML/manifest/图标） | **Cache First** | 永远先用缓存，秒开 |
| CDN 资源（Leaflet / 二维码 / OCR / esm.run） | **Stale While Revalidate** | 先给旧的，后台悄悄更新 |
| 地图瓦片（高德 webrd/webst） | **Cache First（带回填）** | 离线预缓存命中即返；未命中联网回填；上限 5000 张 LRU |
| 实时接口（高德 API / 天气） | **Network Only** | 不缓存，永远走网络（天气离线靠应用层快照） |
| AI 模型权重（ModelScope） | **Network Only** | 达数 GB，绝不能进缓存 |
