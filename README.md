# 🧭 旅行规划 · Travel Planner

一个**装在手机上的私人旅行管家**——行程、地图、票务、记账、酒店、手账，全在一处。

它原本是一个单文件 HTML，现在升级成了 **PWA（渐进式 Web 应用）**：可以添加到手机主屏、点开就是全屏、**断网也能用**，还带一个**在设备本地运行的 AI 助手**（免费、无需账号、数据不出设备）。

> 💡 **一句话理解**：它是一个「不用上架应用商店的 App」。你把它放到任意免费托管上，手机打开、添加到主屏，从此就像原生应用一样用。

## ✨ 功能一览

| 模块 | 能做什么 |
|---|---|
| 📅 **行程管理** | 按天排行程、上下移动调整顺序、自动推断"出发日/游玩日/中转日"、估算里程与车程 |
| 🗺️ **路线地图** | 当日景点自动连线、点击地图选点填坐标、**显示我的实时位置**（蓝点跟随移动） |
| 🚄 **交通票务** | 录入航班/火车/大巴，自动计算中转衔接时间 |
| 💰 **旅行记账** | 手动记账 + **账单截图 OCR 识别**（本地识别，图片不上传）+ 语音记账 |
| 🏨 **酒店住宿** | 登记住宿、入住区间、双床/大床价格、地图定位 |
| 📔 **旅行手账** | 照片配文、三种版式（水彩手账/拍立得/胶片）、一键导出长图 |
| 🎬 **照片视频** | 手账里的照片一键剪成竖屏小视频（1080×1920），可配自己的背景音乐，生成后直接保存/分享 |
| 📝 **行前备忘** | 待办清单 |
| 🤖 **AI 助手** | 本地大模型 / 云端接口（DeepSeek、智谱、SiliconFlow 等）双模式，帮你写行程介绍、景点贴士、酒店信息、出行提醒、手账文案 |
| 📲 **跨设备同步** | 生成二维码，手机扫码即可把行程同步过去（纯前端，无后端） |
| 🧠 **离线知识库** | 覆盖青甘陕等热门景点与 11 座中转城市，自动建议门票/时长/吃玩推荐 |

### 几个贴心设计

- **建议 → 采纳 → 才写入**：知识库和 AI 只给建议，你点了"采纳"才会写进数据，不会乱改你的行程
- **一切可离线**：应用本体、地图库、知识库都会缓存到本地，飞机上也能改行程
- **隐私优先**：OCR 和 AI 都在本地跑，不需要上传任何东西

## 🚀 快速开始

### 方式一：本地直接打开（最快，但无离线能力）

双击 `travel-planner.html` 即可使用，功能和联网版完全一样。

> ⚠️ `file://` 协议下 Service Worker 无法注册，**没有离线缓存**。适合临时看看。

### 方式二：部署到网上（推荐，完整能力）

任选一个免费托管：

<details>
<summary><b>GitHub Pages</b>（免费稳定，适合长期使用）</summary>

1. 登录 [github.com](https://github.com)，新建仓库（选 **Public**）
2. 把本目录下**全部文件**上传到仓库根目录
3. 进入 Settings → Pages → Source 选 `main` 分支 → Save
4. 等 1-2 分钟，访问 `https://你的用户名.github.io/仓库名/`

**⚠️ 上传时注意**：`icons/` 是文件夹，要**整个文件夹拖进去**。如果只把里面的 png 拖进去，会被"拍平"到根目录，导致图标 404（不过我们有兜底，见下文）。
</details>

<details>
<summary><b>Vercel</b>（最简单，拖拽即可）</summary>

1. 访问 [vercel.com](https://vercel.com) 注册
2. Add New → Project → 把本目录整个拖进去
3. 几十秒后拿到 `https://xxx.vercel.app`
</details>

<details>
<summary><b>Netlify / Cloudflare Pages</b></summary>

同理，拖拽文件夹即可，都有免费额度。
</details>

### 方式三：添加到手机主屏（变成 App）

**安卓（Chrome）**
1. 用 Chrome 打开网址
2. 底部会弹「添加到主屏幕」→ 点「添加」
3. 或点右上角 ⋮ → 找**带"安装"字样的那一项**

**iPhone（Safari）**
1. **必须用 Safari**（Chrome 不行）
2. 点底部**分享按钮**（方框带向上箭头）
3. 下滑选**「添加到主屏幕」**→ 右上角「添加」

> ⚠️ **安卓上请认准「安装应用 / 添加到主屏幕」**，不要点「创建快捷方式」——后者只读图标文件，可能显示成灰色的 G。

## 📁 文件说明

```
部署包/
├── index.html                  ← 应用本体（与 travel-planner.html 内容完全相同）
├── travel-planner.html         ← 应用本体（同一份，两个文件名都放，短链也能打开）
├── manifest.webmanifest        ← PWA 清单：应用名、图标、全屏模式
├── sw.js                       ← Service Worker：离线缓存核心（v1.5.0）
├── ai.js                       ← AI 助手：本地模型调用与界面逻辑
├── icons.js                    ← 图标 404 兜底：图标丢失时自动改用内联图标
├── favicon.ico                 ← 浏览器标签页图标
├── favicon-32.png
├── icons/                      ← 应用图标（4 个尺寸）
│   ├── icon-192.png
│   ├── icon-512.png
│   ├── icon-maskable-512.png
│   └── apple-touch-icon.png
├── 示例数据-青甘大环线.json     ← 示例行程（10 天青甘大环线，可导入试用）
├── 部署说明.md                  ← 更详细的部署与排错文档
└── README.md                   ← 本文件
```

**这些文件必须放在同一个目录里**（`icons/` 作为子文件夹），不要拆开。

> 🛡️ **容错说明**：即使 `icons/` 文件夹丢失或路径不对，`icons.js` 会在加载时探测到 404，**自动切换到内联图标并重建 manifest**，不会出现灰底 G。所以容错性比一般 PWA 强。

## 🤖 关于 AI 助手

右下角的 **🤖 悬浮按钮**就是入口。它用 [WebLLM](https://github.com/mlc-ai/web-llm) 把 **Qwen2.5-3B** 模型直接跑在你的设备上。

| 特性 | 说明 |
|---|---|
| **费用** | **完全免费**，没有 API key、不按次计费 |
| **后端** | **不需要**，纯前端 |
| **隐私** | 数据**不出设备**，模型在本地推理 |
| **离线** | 首次联网下载模型（约 1.5GB）后，**断网也能用** |
| **浏览器** | 需支持 **WebGPU**：桌面 Chrome/Edge 113+，安卓 Chrome 121+ |

**五个功能**（生成后可一键「采纳并写入」对应字段）：

- ✍️ 写今日行程介绍 → 写入当天「当日说明」
- 🏞️ 给景点写贴士 → 追加到景点备注
- 🏨 补酒店信息 → 追加到酒店备注
- 🚄 写出行提醒 → 追加到票务备注
- 📔 手账配图文案 → 追加到手账文字

### 模型从哪下载？

优先从 **ModelScope（阿里，国内直连，实测可用）** 下载，失败会自动回退到 `hf-mirror.com` → `huggingface.co`。

> 📌 为什么不直接用 HuggingFace？因为国内访问 `huggingface.co` 会直接超时；而 `hf-mirror.com` 只镜像元数据，真实权重会被 302 跳到 `xethub.hf.co`（同样不可达）。所以国内必须走 ModelScope。

**下载中断了怎么办？** 直接重新点击功能即可，已下载的分片存在 IndexedDB 里，**会接着下，不用从头来**。

### ⚠️ 关于「照片 → AI 绘画」

浏览器本地**跑不了图像生成模型**（太大了）。手账里的「水彩手账 / 拍立得 / 胶片」是**本地 Canvas 风格滤镜**，不是 AI 生成。

想要真正的「照片变水彩画」，需要接入云端图像 API（豆包 / 通义 / OpenAI）——**那就必须配一个后端来藏 key**。这是另一条路，需要时可扩展。

## 💾 数据存储

数据存在**浏览器本地**（localStorage），换设备或清缓存会丢。

**建议做法**：
- 定期用「⬇️ 导出」生成 JSON 备份
- 换设备用「⬆️ 导入」恢复
- 或缺设备间用「📲 分享」二维码直接同步

> ☁️ 云同步（登录账号、多设备自动同步）**已预留接口**（`window.TPSync`），等接入 Supabase 后就不用手动导了。

## ❓ 常见问题

**Q：手机打开还是浏览器界面，有地址栏？**
A：说明没添加到主屏。必须通过上面的方式添加，从桌面图标打开才是全屏。

**Q：图标是灰色的 G / 图标不显示？**
A：按顺序排查：
1. 你点的可能是**「创建快捷方式」而非「安装应用」**——认准带"安装"字样的菜单项
2. `icons/` 文件夹没传对——但 `icons.js` 会自动兜底，一般不用管
3. 浏览器缓存了旧 manifest——清除站点数据后重开

**Q：「我的位置」点不动 / 授权失败？**
A：定位需要三个条件：**https**（github.io 满足）+ **浏览器授权**（首次弹窗选"允许"；误点拒绝可去地址栏左侧站点设置改回）+ **联网**。室内 GPS 弱时精度会降到几百米，属正常。

**Q：「一键定位」和「我的位置」有什么区别？**
A：两个完全不同的功能：
- **📍 一键定位**：把行程里**还没坐标的景点/酒店**批量查经纬度（需配高德 Key）
- **🧭 我的位置**：显示**你本人现在在哪**，蓝点实时刷新（需浏览器定位授权）

**Q：AI 报 `Failed to fetch`？**
A：模型下载失败。确认用的是 Chrome/Edge，且能访问 `modelscope.cn`。重新点功能会从断点续传。

**Q：改了文件但页面没更新？**
A：Service Worker 缓存。清一下站点数据，或留意应用内「✨ 有新版本可用」提示（它会自动弹）。

**Q：iPhone 没看到安装提示？**
A：iOS 不支持自动安装提示。打开约 6 秒后会弹出图文教程，照着做即可。

## 🛠 技术栈

| 层面 | 用了什么 |
|---|---|
| **形态** | 单页 HTML + 原生 JS（无框架、无构建步骤） |
| **PWA** | Web App Manifest + Service Worker（三级缓存策略） |
| **地图** | Leaflet + 高德瓦片（GCJ-02 坐标，含 WGS-84 纠偏） |
| **AI** | WebLLM + Qwen2.5-3B（WebGPU 本地推理） |
| **OCR** | Tesseract.js（本地识别，图片不上传） |
| **二维码** | qrcodejs（生成）+ jsQR（扫描），纯前端跨设备同步 |
| **存储** | localStorage（预留云同步接口） |

### Service Worker 三级缓存策略

| 类型 | 策略 | 说明 |
|---|---|---|
| 应用外壳（HTML/manifest/图标） | **Cache First** | 永远先用缓存，秒开 |
| CDN 资源（Leaflet / 二维码 / OCR） | **Stale While Revalidate** | 先给旧的，后台悄悄更新 |
| 实时接口（高德 API / 地图瓦片） | **Network Only** | 不缓存，永远走网络 |
| AI 模型权重（ModelScope） | **Network Only** | 达数 GB，绝不能进缓存 |
